## Project Description

This project implements an Employee Management System in Java based on the provided UML class diagram.

The project demonstrates Object-Oriented Programming concepts including:

- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Enum
- Association between classes

## Project Classes

- Employee
- CommissionEmployee
- MonthlyEmployee
- HourlyEmployee
- Department
- Gender

## Features

- Calculate employee salaries
- Calculate commission
- Calculate overtime salary
- Calculate additional vacation
- Add employees to a department
- Remove employees from a department
- Find an employee by ID
- Calculate total payroll
- Print all employees
